## 1. 统一行模型与两种使用方式

- **独立数据库页**：点击左侧栏 **「多维表」** 按钮创建，作为独立项目在左侧页面树中展示，默认以宽屏画布呈现。
- **文档内嵌数据库**：在任意普通文档输入 `/内嵌多维数据库` 创建，直接嵌在正文流中与文字混排。
- **行详情抽屉与全页打开**：点击表格中的记录标题或看板/日历/画廊卡片，会从右侧滑出 **行详情抽屉 (`RowPeekDrawer`)**——上半部分表单支持直接修改所有字段、查看实时公式/汇总结果、单行触发 AI 填充；下半部分直接挂载完整 `BlockEditor` 编写记录正文；点击抽屉左上角 **「作为全页打开」** 可进入独立页面视图。

## 2. 四大核心视图与数据交互

创建数据库时默认初始化 4 个视图，你也可以通过视图栏右侧 `+ 视图` 自由创建多个自定义视图并随时切换或删除（至少保留 1 个视图）：

| 视图 | 核心交互与适用场景 |
| --- | --- |
| **表格视图 (`Table`)** | 高密度电子表格模式，支持全字段单元格原地编辑、新增下拉选项、点击 `+ 字段` 拓展列，以及底栏每列的实时聚合统计（计数 / 非空 / 求和 / 均值） |
| **看板视图 (`Kanban`)** | 按任意「单选」或「复选框」字段自动分列分组（包含「未分类」列），支持 **拖放卡片跨列变更状态** 并自动写回数据库，每列顶部 `+` 号可直接在该分组下新建记录 |
| **日历视图 (`Calendar`)** | 月历网格映射任意「日期」字段，支持切换上/下月及快速回到「今天」，鼠标悬停任意日期单元格右上角 `+` 可直接创建该日期的日程记录 |
| **画廊视图 (`Gallery`)** | 卡片网格展示模式，自动渲染页面封面图或正文前 4 行摘要与最多 4 个关键属性徽章，适合读书卡片、灵感库、项目案例库 |

## 3. 筛选、排序与聚合统计

- **顶部快速搜索**：实时按记录标题或任意字段展示值过滤当前视图。
- **条件筛选器 (`Filter`)**：支持叠加多条筛选规则（每条规则选择 `字段 + 运算符 + 匹配值`），并自动持久化到当前视图配置中。支持运算符包括：
  - 文本/通用：`包含 (contains)`、`不包含 (not_contains)`、`等于 (equals)`、`不等于 (not_equals)`、`为空 (is_empty)`、`非空 (is_not_empty)`
  - 数值/日期：`大于 (gt)`、`小于 (lt)`、`大于等于 (gte)`、`小于等于 (lte)`
  - 复选框：`已勾选 (is_checked)`、`未勾选 (is_not_checked)`
  > 注：视图筛选界面提供了最常用的 8 个选项，引擎层完整支持以上全部 12 种运算。
- **多字段排序 (`Sort`)**：支持叠加多列 `升序 (asc)` / `降序 (desc)` 排序（支持对公式列与汇总列进行排序），中文字段采用 `zh-CN` 拼音顺序排序。

## 4. 18 种字段类型全览

点击工具栏 **「字段设置」** 可添加、重命名、配置或删除字段（`title` 标题主列保留不可删除）：

| 分类 | 字段类型 (`type`) | 说明 |
| --- | --- | --- |
| **主列** | `title` | 记录名称（与关联页面标题双向同步） |
| **基础输入** | `text`、`number`、`date`、`checkbox` | 文本、数字（支持纯数字 / 人民币 `¥` / 百分比 `%` 格式）、日期 (`YYYY-MM-DD`)、复选框 |
| **分类标签** | `select`、`multi_select` | 单选与多选彩色标签，支持在管理弹窗配选项或直接在表格单元格里输入新增选项 |
| **联系与资源** | `url`、`email`、`phone`、`person`、`files` | 可点击直达的 URL、邮箱、电话、负责人、本地文件/附件上传 |
| **系统时间戳** | `created_time`、`updated_time` | 自动展示记录创建时间与最后更新时间 |
| **高级计算与 AI** | `relation`、`rollup`、`formula`、`ai_autofill` | 跨库双向关联、关联数据汇总、AST 公式计算、AI 自动生成列 |

## 5. 双向关联 (Relation) 与汇总 (Rollup)

### 双向关联 (`relation`)
1. 在「字段设置」新增字段并将类型设为 **关联 (Relation)**，选择 **「关联目标数据库」**（支持跨库关联，也支持关联自身数据库）。
2. 勾选 **「开启双向关联」** 并保存后，后端事务会自动在目标数据库中创建一个反向关联字段（名为 `<源数据库名> 关联`）。
3. 之后无论你在哪一端勾选或移除关联记录，服务端都在同一个数据库事务中自动计算增删差集并同步写回对端记录，确保双向数据永远一致。

### 汇总 (`rollup`)
创建 **汇总 (Rollup)** 字段需依次配置 3 项：
1. **选择关联列**：选择一个已有的 `relation` 字段；
2. **目标库字段**：选择关联目标库中要汇总的字段（甚至可以是目标库中的 `formula` 公式列）；
3. **汇总计算方式（共 14 种）**：
   - 计数与占比：`count_all`（计数全部关联项）、`count_values`（计数非空值）、`count_unique`（计数去重）、`count_empty`（计数空值）、`percent_not_empty`（非空百分比）、`percent_empty`（空值百分比）
   - 数值统计：`sum`（求和）、`avg`（平均值）、`median`（中位数）、`min`（最小值）、`max`（最大值）、`range`（极差：最大值减最小值）
   - 值展示：`show_original`（显示全部原始值）、`show_unique`（显示去重值）

## 6. 完整 AST 公式引擎参考（52 个函数）

Woqu 内置自研纯 TypeScript **词法分析 (`lexer.ts`) + Pratt 递归下降语法分析 (`parser.ts`) + 求值器 (`evaluator.ts`)**，完全不依赖 `eval()`，安全且支持在「字段设置」中 **实时语法错误检测 + 基于首行记录的实时结果预览**。

### 运算符与常量
- **算术**：`+` `-` `*` `/` `%`（注意：`+` 两侧任一为字符串时执行字符串拼接；除数或模数为 `0` 时安全返回 `#DIV/0!`）
- **比较**：`==` `!=` `>` `>=` `<` `<=`
- **逻辑与三元**：`&&` `||` `!` `条件 ? 真值 : 假值`
- **内置常量**：`true`、`false`、`pi` / `PI`、`e` / `E`
- **错误保护**：公式之间互相引用时自动做拓扑递归求值，若发现循环引用会安全返回 `#CYCLE!` 而不是卡死页面。

### 函数全清单

#### 逻辑与字段读取（8 个）
| 函数签名 | 说明 |
| --- | --- |
| `prop("字段名")` | 按字段名称或字段 ID 读取当前行值（支持读取 `rollup` 与嵌套 `formula` 结果，也可直接引用 `"title"` / `"名称"` / `"created_at"` / `"updated_at"`） |
| `if(条件, 真值, 假值)` | 短路条件分支判断 |
| `ifs(条件1, 值1, 条件2, 值2, ..., [兜底值])` | 多条件顺序匹配，支持最后一个参数作为默认兜底值 |
| `and(条件1, 条件2, ...)` | 全部条件为真时返回 `true`（短路求值） |
| `or(条件1, 条件2, ...)` | 任一条件为真时返回 `true`（短路求值） |
| `not(值)` | 逻辑取反 |
| `empty(值)` | 判断是否为空值（`null`、`undefined`、`""` 或空数组 `[]` 均返回 `true`） |
| `coalesce(a, b, ...)` | 返回参数列表中第一个非空的值 |

#### 字符串处理（14 个）
| 函数签名 | 说明 |
| --- | --- |
| `concat(a, b, ...)` | 将多个值按字符串拼接 |
| `join(分隔符, 列表或多项...)` | 使用指定分隔符连接数组或多项参数 |
| `contains(文本或列表, 目标)` | 判断字符串是否包含子串，或数组是否包含某元素 |
| `length(文本或列表)` | 返回字符串长度或数组元素个数 |
| `slice(值, start, [end])` | 截取字符串或数组片段 |
| `substring(值, start, [end])` | 同 `slice`，截取子串或子数组 |
| `lower(文本)` / `upper(文本)` | 转为全小写 / 全大写 |
| `trim(文本)` | 去除首尾空白符 |
| `replace(文本, 正则, 替换文本)` | 使用正则表达式替换首个匹配项 |
| `replaceAll(文本, 旧串, 新串)` | 全局字面量替换所有匹配子串 |
| `split(文本, 分隔符)` | 按分隔符拆分为字符串数组 |
| `test(文本, 正则)` | 判断文本是否匹配正则表达式，返回布尔值 |
| `format(任意值)` | 将数字、日期、布尔或数组格式化为易读字符串 |

#### 数学与统计（12 个）
| 函数签名 | 说明 |
| --- | --- |
| `round(数字, [小数位数])` | 四舍五入（默认保留整数） |
| `floor(数字)` / `ceil(数字)` | 向下取整 / 向上取整 |
| `abs(数字)` | 取绝对值 |
| `sqrt(数字)` / `pow(底数, 指数)` | 平方根 / 幂运算 |
| `mod(被除数, 除数)` | 取余（除数为 `0` 返回 `#DIV/0!`） |

#### 日期与时间（12 个）
| 函数签名 | 说明 |

#### 列表与数组（6 个）
| 函数签名 | 说明 |
| --- | --- |
| `count(值)` | 数组返回长度，非空标量返回 `1`，空值返回 `0` |
| `unique(列表)` | 对数组元素去重 |
| `flat(...)` | 展平嵌套数组并过滤空项 |
| `first(列表)` / `last(列表)` | 返回列表第一个 / 最后一个元素 |

## 7. 高频实用公式范例

```javascript
// 1. 任务截止倒计时状态提示
if(prop("状态") == "已完成", "✅ 已完成",
  ifs(
    empty(prop("日期")), "⏳ 未排期",
    dateBetween(prop("日期"), today(), "days") < 0, concat("🚨 已逾期 ", abs(dateBetween(prop("日期"), today(), "days")), " 天"),
    dateBetween(prop("日期"), today(), "days") == 0, "🔥 今天截止",
    concat("📅 剩余 ", dateBetween(prop("日期"), today(), "days"), " 天")
  )
)

// 2. 订单含税金额计算（保留 2 位小数）
round(prop("单价") * prop("数量") * 1.13, 2)

// 3. 根据关联项目汇总工时计算预估成本
if(empty(prop("总工时")), 0, round(prop("总工时") * 350, 2))

// 4. 多标签拼接美化展示
empty(prop("标签")) ? "无标签" : join(" · ", prop("标签"))
```

## 8. AI 自动填充列 (AI Autofill)

在数据库中添加 **AI 自动生成 (`ai_autofill`)** 列后，你可以：
1. 在 **「字段设置」** 中填写 **AI 生成指令 (Prompt)**（例如：「根据标题和正文内容，提炼 1 条核心风险与应对建议」）；
2. 勾选需要作为上下文传给大模型的 **源字段 (`ai_source_prop_ids`)**（服务端还会自动附上该行页面的标题与前 2500 字正文）；
3. 回到表格后：
   - **批量生成**：点击工具栏紫色的 **「AI 填充 (<字段名>)」** 按钮，服务端会自动为当前列**所有为空单元格**批量生成并填入结果；
   - **单行刷新**：将鼠标悬停到某一行的该列单元格上或打开行详情抽屉，点击小星星图标 ✨ 即可单独生成或覆盖刷新该行。
