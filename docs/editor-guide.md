# ✏️ 块级富文本编辑器完全手册

Woqu 编辑器基于 **TipTap v2 (ProseMirror)** 深度定制，结合 Wolai 的柔色排版美学与 Notion 的块级操作哲学，同时通过 `UniqueBlockId` 扩展为每个顶层内容块自动维护全局唯一锚点 ID，支持中文输入法稳定输入与精确撤销重做。

## 2. 左侧悬浮 `+` 与 `⋮⋮` 拖拽手柄

在桌面端（视口宽度 ≥ 768px），将鼠标悬停到正文任意顶层块上时，左侧边距会出现两个操作手柄：

- **`+` 按钮**：在当前块下方立即新建一段并自动填入 `/`，方便连续插入新块。
- **`⋮⋮` 拖拽手柄**：
  - **直接按住拖拽**：可将当前块上下拖放到文档中的任意位置重新排序。
  - **单击打开块操作菜单**：
    - **转换为**：一键将当前块转为 `正文`、`H1`、`H2`、`H3`、`列表`、`待办`；
    - **让 AI 优化该块**：无需手动划词，直接将整块文字发给 AI 进行润色优化；
    - **复制块**：在下方克隆一个相同内容的块（自动分配新 `blockId`）；
    - **复制块锚点链接**：复制形如 `/p/<pageId>#block-<blockId>` 的精确锚点 URL；
    - **删除块**：移除当前块。

## 3. 高级内容块详解

### 柔色提示块 (Callout)
点击提示块左上角的 Emoji 图标，会弹出配置浮层：
- **8 种常用提示图标**：`💡` `📌` `⚠️` `✅` `🔥` `🚀` `💬` `✨`
- **8 种 Wolai 柔色背景**：蓝 (`blue`)、灰 (`gray`)、绿 (`green`)、黄 (`yellow`)、橙 (`orange`)、红 (`red`)、紫 (`purple`)、粉 (`pink`)，深色模式下自动适配柔和暗色护眼色值。

### 代码块与 Mermaid 实时图表
- 顶部栏内置 12 种语言选项：`自动 / Plain`、`Mermaid 图表`、`TypeScript`、`JavaScript`、`Go`、`Python`、`SQL`、`JSON`、`Shell / Bash`、`CSS`、`HTML`、`Markdown`。
- 当语言选择为 **Mermaid 图表 (`mermaid`)** 时：
  - 默认以 **「只看图」** 模式实时渲染流程图、时序图、类图、状态图、ER 图等；
  - 双击图表区域或点击右上角 **「编辑源码」** 按钮可切换出代码编辑器修改源码，修改后约 `250ms` 自动重新渲染；若语法有误会在图表区显示清晰报错而不会影响整页编辑。

### LaTeX 数学公式 (`KaTeX`)
- 块级公式 (`mathBlock`)：点击渲染后的公式区域即可打开 LaTeX 编辑框，支持标准 KaTeX 语法（如 `\sum_{i=1}^n x_i = S`），点击 **「完成」** 实时预览。
- 行内公式 (`mathInline`)：点击行内公式标签即可原地修改表达式并按 `Enter` 确认。

### 内嵌多维数据库
通过 `/内嵌多维数据库` 插入的表格并非静态表格，而是一个独立的真实数据库实例（`is_inline = true`）：你可以直接在文章正文中切换它的表格、看板、日历或画廊视图，也可以点击行记录弹出右侧抽屉填写详情正文。

## 4. `[[` 页面双向链接

- 输入两个左方括号 `[[` 即可呼出页面检索菜单，输入标题关键词过滤后按 `Enter` 插入链接胶囊。
- 点击蓝色页面胶囊会直接跳转到目标页面，目标页面右侧 **「反链」** 面板与全局 **「双向链接图谱」** 会自动同步更新关联关系。

## 5. 划词浮动工具栏与 AI Diff 预览

用鼠标拖选任意一段正文文字时，选区上方会自动弹出纯 React Portal 浮动工具栏：

- **基础富文本格式化**：加粗 (`Bold`)、斜体 (`Italic`)、下划线 (`Underline`)、删除线 (`Strike`)、行内代码 (`Code`)、高亮背景 (`Highlight`)、超链接 (`Link`)。
- **AI 优化下拉菜单**：
  - 顶部输入框支持**临时自由输入自定义指令**（例如「改写成三条要点」或「改成轻松的博客口吻」）；
  - 下方列表直接调用 8 个内置指令与你在设置中心创建的所有自定义 Prompt 模板。
- **可视化词级 Diff 预览面板 (`AiDiffPanel`)**：
  - 点击任意 AI 指令后，编辑器下方会出现流式生成预览框；
  - 生成完毕后，系统会自动计算原文与新文本的 **词级/中文字级 LCS Diff 对比**（红色删除线为删去部分，绿色高亮为新增部分）；
  - 提供 4 个精准落地按钮：**「替换选中」**、**「插入下方」**、**「重新生成」**、**「丢弃」**。
