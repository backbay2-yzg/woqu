## 1. 首次初始化与工作区安全

首次打开 `http://localhost:8080` 时，系统会进入 **初始化引导页**：

1. **设置工作区图标与名称**：例如 `✨ 我趣知识库`，后续可随时在左下角 **「系统与 AI 设置 → 外观与工作区」** 修改。
2. **选择鉴权模式**：
   - **密码保护模式（推荐，公网/局域网部署必选）**：设置至少 4 位登录密码，服务端通过 `bcrypt` 加盐哈希存储，登录后签发 `HttpOnly` JWT Cookie（有效期 30 天）。
   - **本机免登录模式**：勾选后无需输入密码即可直接进入工作区，仅建议在纯本地 `localhost` 环境下使用。
3. **自动开箱引导数据**：初始化完成后，系统会自动创建两份示例内容帮助你快速体验：
   - `🚀 欢迎使用我趣文档`：包含 Callout 提示块、待办清单与 Mermaid 架构图示例。
   - `📋 项目任务看板`：预置表格、看板、日历、画廊四视图的多维数据库。

> [!NOTE]
> 如需切换安全模式或修改密码，点击左侧栏底部 **「系统与 AI 设置 → 密码与安全」** 即可。若从免登录模式切换为密码模式且此前未设过密码，界面会要求设置一个至少 4 位的新密码。

## 2. 三栏式工作区布局与导航

Woqu 采用兼具 Wolai 温润阅读美感与 Notion 高信息密度的三栏结构：

1. **左侧导航栏 (`Sidebar`)**：
   - 顶部：工作区标题、浅色/深色主题一键切换按钮（☀️ / 🌙）。
   - 搜索与新建区：`搜索知识库... (⌘K)`、`新建页面`、`多维表` 快捷按钮。
   - 树形导航区：**收藏夹** 与 **全部页面** 层级树。
   - 底部工具区：**使用文档**、**双向链接图谱**、**页面模板中心**、**网页智能剪藏**、**导入导出与备份**、**回收站**、**系统与 AI 设置** 及退出登录按钮。
   - 桌面端可折叠侧边栏，移动端会自动切换为点击汉堡菜单滑出的抽屉层。
2. **中央编辑画布**：
   - 顶部工具栏显示当前页面标题与实时保存状态（`正在保存...` / `已保存`，输入防抖约 `450ms` 自动落盘）。
   - 右上角工具按钮依次为：**收藏星标 ⭐**、**宽屏/标准阅读宽度切换**、**历史版本与快照**、**公开只读分享**、**导出入口**、**大纲**、**反链**、**AI 助手**。
   - 文档标题下方支持自由添加/删除 `#标签`。
3. **右侧按需滑出面板**：
   - 支持在 **AI 助手**、**文档大纲 (TOC)** 与 **反向链接** 三个面板间按需切换或关闭，不占日常写作宽度。

## 3. 无限层级页面树、收藏与回收站

- **新建子页面**：鼠标悬停在左侧页面树的任意页面行上，点击右侧出现的 `+` 按钮即可在该页面下新建子页面。
- **拖拽整理层级**：直接按住左侧页面树中的任意页面拖放到另一个页面上，即可将该页面移动为目标页面的子页面（系统会自动阻止“移动到自身后代”造成的死循环）。
- **复制与收藏**：悬停点击复制图标可快速创建 `(副本)` 页面；点击顶部星标按钮可将常用文档固定到侧边栏顶部 **「收藏夹」**。
- **回收站安全删改**：点击删除不会立即丢失数据，而是将页面及子页面移入 **「回收站」**。进入左下角 **「回收站」** 可一键 **恢复**（若原父页面也在回收站中，恢复后自动回到根目录）或 **彻底删除**。

## 4. 全局混合搜索 (`Cmd/Ctrl + K`)

在任意界面按下 `Cmd + K`（Mac）或 `Ctrl + K`（Windows/Linux），或点击左侧搜索框即可呼出全局命令与检索面板：

- **无输入时**：展示快捷操作（新建空白文档、新建多维数据库、打开知识图谱、切换浅/深主题）与最近编辑的页面列表。
- **输入关键词时**：调用后端 `/api/v1/search` 混合检索引擎：
  - **中文短词精确命中**：内置 `SegmentCJK` 中文分词器与 SQLite FTS5 `BM25` 权重排序（标题权重最高），即使输入 **“看板”“摘要”“公式”** 等 2 字中文词也能毫秒级精准命中并高亮展示正文摘录。
  - **语义混合增强**：如果你在 AI 设置中心配置了 Embedding 向量模型，系统会自动将向量余弦相似度与 FTS5 排名通过 **RRF（Reciprocal Rank Fusion）** 算法融合排序。

## 5. 双向链接、反向链接与知识图谱

- **建立双向链接**：在编辑器任意位置输入 `[[`，会弹出全库页面搜索浮层，选择目标页面后即可插入可点击跳转的蓝色关联胶囊。
- **查看反向链接**：点击右上角 **「反链」** 按钮，右侧面板会实时列出所有引用了当前页面的文档，并展示引用所在段落的上下文摘录。
- **交互式知识图谱 (`Graph View`)**：点击左侧栏底部的 **「双向链接图谱」**，打开基于 HTML5 Canvas 的力导向图谱：
  - 绿色节点代表 **多维数据库**，靛蓝节点代表 **普通文档**；节点半径随关联度自动放大。
  - 支持 **按标题或 `#标签` 实时过滤**、**滚轮缩放**、**画布平移**、**拖拽节点固定布局**、悬停高亮相邻节点与连线，以及 **点击/双击节点直接跳转至对应文档**。

## 6. 悬浮大纲目录 (TOC) 与历史版本回滚

- **实时大纲**：点击右上角 **「大纲」** 按钮打开 TOC 面板，编辑器会自动提取全文所有 `H1 / H2 / H3` 标题并按层级缩进，点击任意标题即可平滑滚动定位到对应块。
- **三类历史版本快照**：点击右上角时钟图标打开 **「页面历史版本与快照」**，每篇页面最多保留最近 80 份版本，分为三类来源：
  - **自动保存 (`auto`)**：编辑发生变更时自动节流快照（若距离上次自动快照不足 5 分钟或内容无变化则自动跳过，避免冗余）。
  - **手动快照 (`manual`)**：点击弹窗右上角 **「保存当前快照」** 随时记录里程碑。
  - **AI 修改前快照 (`pre_ai`)**：每当 AI Agent 即将改写现有页面或数据库记录前，系统都会强制先存一份安全快照。
- **预览与一键回滚**：在左侧时间线选择任意快照，右侧会完整渲染当时的文档内容，点击 **「一键恢复到此版本」** 即可回滚（回滚前系统还会额外创建一份 `pre_restore` 备份以防误操作）。

## 7. 页面模板中心

点击左侧栏底部的 **「页面模板中心」** 打开模板库：

- **内置 5 套高质量中文模板**：
  1. `🗓️ 高效会议纪要`（基本信息、议题决议、可追踪 Action Items 待办）
  2. `📊 个人工作周报`（本周核心产出、风险思考、下周重点计划）
  3. `📚 深度读书笔记`（书籍档案、一句话总结、金句摘录、落地清单）
  4. `🚀 项目推进方案 (PRD)`（背景目标、模块优先级表格、里程碑）
  5. `🎯 季度 OKR 目标复盘`（Objective 与 KR 量化拆解、复盘反思）
- **存为自定义模板**：打开任意满意的文档后进入模板中心，在右下角输入模板名称即可将当前文档结构保存为可重复使用的自定义模板。

## 8. 网页智能剪藏 (Web Clipper)

点击左侧栏底部 **「网页智能剪藏」**，输入文章的 `http://` 或 `https://` 网址：

1. 后端会自动抓取网页 HTML，优先识别 `<article>` / `<main>` 主体内容区域并剥离导航栏、页脚与脚本。
2. 自动保留标题层级、段落、列表、引用、代码块、链接与图片，转换为 Woqu 标准块级文档，并在顶部自动插入带原文链接的 **网页书签卡片**。
3. 勾选 **「剪藏后顺手使用 AI 生成核心摘要与行动项」** 时，会在保存页面后自动调用摘要模型提炼要点（即使暂未配置 AI，网页正文仍会完整保存）。

> [!IMPORTANT]
> **SSRF 安全防护**：默认状态下，服务端在 DNS 解析和底层网络连接阶段均会拦截内网私有 IP（如 `127.0.0.1`、`10.x`、`192.168.x`、`169.254.x`）和 `.local` / `.internal` 地址；如确有在内网环境剪藏本地服务的需要，可在启动环境变量中设置 `WOQU_ALLOW_PRIVATE_CLIP=1`。

## 9. 单页只读公开分享

点击页面右上角 **分享图标**，即可为当前页面生成独立只读公开链接（格式为 `/share/<随机Token>`）：

- **免登录浏览**：访客无需知道工作区密码即可打开页面，文档内部嵌入的多维数据库也会以只读快照方式正常显示表格/看板/日历/画廊视图。
- **可选访问密码**：填写密码后，访客必须先通过密码解锁表单才可读取正文内容。
- **可选过期时间与随时撤销**：支持设置到期日期、临时暂停启用开关，或点击 **「彻底撤销分享链接」** 使旧链接立即失效；卡片上方同步统计累计访问次数。

## 10. 导入、导出与整库热备份还原

点击左侧栏底部 **「导入导出与备份」**（或页面右上角压缩包图标）：

### 导出当前文档
- **导出 Markdown (`.md`)**：自动附带标签与摘要的 YAML Frontmatter，并完整还原标题、列表、待办、Callout、折叠块、代码块、表格、公式与 `[[双链]]`；若为多维数据库页面，末尾会附带完整 Markdown 数据表格。
- **导出独立 HTML (`.html`)**：生成带内嵌样式的单文件网页，可直接发送他人离线打开。
- **打印 / 导出 PDF**：调用系统原生打印样式表（自动隐藏侧边栏与操作按钮，保留干净排版与 KaTeX 公式），在浏览器打印弹窗选择 **「另存为 PDF」** 即可零依赖导出高保真 PDF。

### 导入外部笔记
- **批量导入 Markdown**：支持一次多选多个 `.md` / `.markdown` 文件批量导入为页面。
- **导入 Notion Export Zip**：直接上传从 Notion 导出的 Markdown & CSV 压缩包（支持外层嵌套 Zip），系统会自动：
  1. 清洗 Notion 文件名末尾自带的 32 位十六进制 ID；
  2. 重建目录与父子页面层级结构；
  3. 提取包内图片保存至 `data/uploads/` 并重写图片路径；
  4. 将页面间的相对 `.md` 链接自动转换为 Woqu `[[pageMention]]` 双向链接；
  5. 将 Notion 的 `.csv` 数据库自动导入为 Woqu 多维数据库与行记录。

### 整库热备份与迁移
- **下载整库热备份 (`.zip`)**：后端通过 SQLite 原生 `VACUUM INTO` 生成一致性热备份数据库，并连同整个 `data/uploads/` 附件目录一起流式打包下载，无需停止服务。
- **从备份压缩包还原**：上传此前导出的 `.zip` 备份包后，服务端会先在临时目录校验 SQLite 头与核心表结构并防路径穿越，验证通过后原子热切换当前数据库连接与附件目录。
